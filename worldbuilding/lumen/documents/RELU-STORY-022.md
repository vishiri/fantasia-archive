越接近第五层后段、越接近结尾，剧情本身开始让观众产生一种：「这个宇宙正在变得精神上不可整理」的感觉。
这跟堆猎奇设定、让角色发疯、制造「看不懂」的效果都没关系。
```
世界的混乱 → 信息与关系的高度耦合 → 叙事结构本身开始承载这种复杂度 → 观众的认知模型出现失稳
```

## 关键叙事原则

第五层不能简单地「把剧情写乱」，而应该：
> 「让一个本来存在结构的系统，逐渐超出观察者能够稳定建模的范围。」
```
有秩序 → 高度复杂的秩序 → 无法完整压缩的秩序 → 主观体验为混乱
```
$$Chaos
eq 没有秩序 \qquad Chaos \approx Complexity > Observer\'s\ modeling\ capacity$$

## 100 声部对位模型

前期：声部各自可辨。后期：大量声部同时运动并彼此耦合，观众逐渐无法同时保持所有声部的完整模型。
>  重要：「听不清」≠「没有结构」。相反：越混乱，背后的结构可能越庞大。

## 最终效果

> 观众不再只是问「这个宇宙到底是什么？」，而开始产生：「我可能根本没有能力把这个宇宙完整理解。」
于是最终主题不需要由角色直接宣告，而由观众自己的观看体验得出。
