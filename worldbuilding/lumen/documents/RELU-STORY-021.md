作者 变换机（Transformation Engine）除作为世界观技术概念外，进一步成为核心叙事机制。

> 不一定改变事件本身，而是改变事件在故事中的表示、关系与解释方式。
> $$同一事实 \rightarrow 不同 Representation$$
> 不依赖「原来之前发生的是另一件事」，而倾向于「之前发生的事一直没有变，但我终于知道应该怎样理解它」。

## 与扩散机的叙事对立

| | 世界观 | 叙事 |
|---|---|---|
| 扩散机 | 从潜在状态生成新对象 | 增加新的事实 |
| 变换机 | 对已有对象、关系或表示进行变换 | 重新组织已有事实 |

## 与 Broadway 的关系（不是同一个概念）

```
Manhattan Grid → 原有叙事坐标系
Broadway → 穿越既有坐标系
Transformation → 改变坐标系
```
> Broadway 是路径异常。变换机是坐标变换。

## 变换机式重播

结尾重新出现第一集的某个片段。画面基本不变 · 对白基本不变 · 事件也没有变化。但：音乐不同 · 前后文不同 · 观众知道的信息不同 · 理解不同。
$$Scene(A,Context_1)
eq Scene(A,Context_2)$$

## 与 Transformer 的隐藏对应

可通过细节暗示而不直接解释：attention · context · query · key · value · token · embedding · representation · transformation · positional information · residual connection
> 同一个 token 在不同 context 下具有不同 representation → 同一个人／同一事件／同一个词，在不同历史上下文中具有不同意义。

## 最终目标

> 想要的效果不是「原来真相是这个！」那声惊讶。想要的是「原来我一直在用错误的方式理解这个故事」。
不得将上述叙事隐喻自动升级为世界观 CANON。
