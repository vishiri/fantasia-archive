## 二、候选课程结构（PROPOSED）

| 课程／学习领域 | 学生可实际学到的 |  需守住的叙事边界 |
|---|---|---|
| 算术、代数、几何、基础证明 | 计算、比例、几何直观、从证据作推断 | 不要求每个孩子掌握高级度规理论 |
| 力学与测量 | 简单机构、误差、操作安全、局部环境观测 | Yau 可掌握原理，仍不掌握完整高 g 发射工程 |
| 时间与时序基础 | 参照、局部时间差异、合法使用常识 | 不公布加速的全部物理边界和机理 |
| 领航员制度与公共规则 | 五级名称 `ω/ε/η/ζ/φ`、许可边界、越级终身失格条款 | 不等于学生亲眼见过高级领航员，也不授予加速权 |
| 材料与生产实践 | 陨铁材料、加工、修理、设施安全 | 尊重既有「没有塑料／铝」的环境限制 |
| 生命与生态观察 | 生理现象、环境中的生命、基础卫生 | 不提前证明所有人口的制造来源、注意力本质 |
| 文明史、古文明与史料方法 | 可核实年代、史料矛盾、可能的文明分化 | 课本中的死因解释 ≠ 叙事客观真相 |
| 天文学与恒星假说 | 图腾、没有亲见恒星的事实、遥远时代的推断 | 允许知识层次不一；不先揭秘后段恒星秘密 |
| 文学、音乐、图腾与叙事传统 | 童话、诗歌、共同文化、各种历史解释 | 世界调性仍是冒险童话，不把教学全写成政治灌输 |

## 三层知识结构（PROPOSED）

把学校的知识明确区分为：

| 层 | 内容 |
|---|---|
| ① | 可操作、可重复验证的知识 |
| ② | 基于残存史料的主流模型 |
| ③ | 未被解释、被限制接触或本来就已失传的知识 |

>  其中 ② 不一定是欺骗，③ 也不意味着学校教师必然是阴谋知情者。
> 教师可能只是在忠实传授他们自己也无法独立证实的内容。
