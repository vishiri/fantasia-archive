作者 领航员与手术师系统改为【环的等级】。

由高到低八级：
1. 正void环
2. 镶void环
3. 正int环
4. 镶int环
5. 正float环
6. 镶float环
7. 正double环
8. 镶double环

`void` 环承载此前已确立的 `∅` 象征，必须与它已有的含义保持连接——包括黑洞／生存环境的含义。
不要把 `∅` 简化成单纯的「空／无」。

「正」与「镶」的确切含义、能力、社会特权、制度结构，在另行确立之前均未完全指定。

结构观察（评估者提，未裁定）：
- 四组类型 void → int → float → double 与编程语言的类型名相同
- 类型同名不自动规定能力或容纳量；`void` 对应 `∅` 的已有多重意向
- 而 `∅`（空集）正是 `void` 那一档——最高一级
若这个顺序成立，那它说的是【能容纳／能表示多少】

与已确立内容的接续：
- 已有 `领航员之环`：陨铁打造、由仪式授予、形制与图腾相同（`RELU-TECH-013`）
- 已有 社会阶层：手术师是高等阶层，领航员是「无法理解的神」（`RELU-SOCI-001`）
- 已有 `∅`：发射器曾用名（`RELU-TECH-001`）
本体系把「环」从一件器物升格成了整套等级。
